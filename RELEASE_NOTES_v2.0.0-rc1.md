# AutoGreyR v2.0.0-rc1 Release Notes

## Release type
Research/reproducibility release candidate.

## Headline scientific result
The prospectively protected REALBENCH3 confirmation **did not pass the primary selector-value gate**. P11-C remains FAIL / CLOSED and was scored exactly once. This release is not evidence that AutoGrey V2 externally outperforms AutoGreyR v1.0.0.
