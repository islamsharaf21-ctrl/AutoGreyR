# AutoGreyR V2

**Release candidate:** `v2.0.0-rc1`  
**R5-B5 decision:** tag/package **AUTHORIZED** after R5-B4 clean-room verification.  
**Stable `v2.0.0` is not authorized.**

AutoGrey V2 is a governed cross-task selector over heterogeneous grey forecasting-family actions. The legal action set is task-specific and is constructed before selection from frozen mathematical admissibility, full-refit validity, structural-reduction, forecast-collision ownership and refusal rules.

## Scientific status

- AutoGreyR `v1.0.0` remains immutable.
- Formal V2 P0–P10: PASS / CLOSED.
- P11-A: PASS / CLOSED.
- P11-B: PASS / CLOSED.
- P11-C: **FAIL / CLOSED** and was scored exactly once.
- No externally validated performance-improvement claim over `v1.0.0` is authorized.

The protected REALBENCH3 primary confirmation gate failed. That result is preserved. A later read-only forensic audit identified specification-conforming SG08_WBO recursive amplification on two extremely sparse intermittent car-parts series as the dominant mechanism behind the extreme aggregate; those parents are not removed, clipped, winsorized or rescored.

## What this release candidate contains

This source-only research release candidate contains portable AutoGrey V2 scientific source, public-safe frozen scientific contracts, aggregate frozen P11-C outputs, deterministic REALBENCH3 source acquisition/checksum verification, P1-seal verification, evidence-derived Python/R environment locks, Apache-2.0 licensing, and public reproducibility documentation.

It deliberately does **not** contain raw REALBENCH3 source archives, REALBENCH3 target/development binary payloads, target indices, protected opening evidence, detailed private parent/bootstrap ledgers, recovery/audit archives, or personal machine paths.

## Data boundary

REALBENCH3 source data are third-party materials. This repository publishes source identifiers, citations, frozen checksums and acquisition/verification tooling, but **does not redistribute those data bytes**.

## Reproducibility limitation

The exact original P1 acquisition/reservation runner has not been recovered. The release provides deterministic source-byte acquisition and independent P1-seal verification, but does **not** claim that the complete historical source → reservation → P1-seal generation pipeline is self-contained.

The exact historical `statsmodels` version remains `UNRESOLVED_DO_NOT_INVENT`; it is not part of the frozen Python core preflight.
